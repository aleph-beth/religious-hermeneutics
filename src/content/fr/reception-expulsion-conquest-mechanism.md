**Type** : Analyse structurelle
**Thèse** : La relation Europe-Islam entre le XIIe et le XXe siècle suit un schéma invariant en trois phases : réception du savoir → expulsion des transmetteurs → conquête avec les outils reçus.

---

## 1. Phase 1 : Réception (XIIe-XVe siècles) {#s1}

**Mécanisme** : L'Europe traduit, copie et assimile le savoir arabo-andalou. Les portes d'entrée sont Tolède (reconquise en 1085), Palerme (Sicile normande), Montpellier et Salerne. Les traducteurs sont majoritairement juifs — intermédiaires trilingues (arabe-hébreu-latin) entre deux mondes en guerre.

**Contenu transmis** :

| Domaine | Savoir | Source |
|---------|--------|--------|
| Philosophie | Aristote + commentaires d'Averroès | Cordoue → Tolède → Paris |
| Astronomie | Astrolabe, tables astronomiques | Al-Zarqali (Cordoue) → Zacuto |
| Mathématiques | Algèbre, algorithme, zéro, base 10 | Al-Khwarizmi (Bagdad) → Al-Andalus |
| Navigation | Voile latine, cartographie portulane | Dhows arabes → caravelle |
| Militaire | Poudre à canon, artillerie | Chine → Hasan al-Rammah → Al-Andalus |
| Médecine | Canon d'Avicenne, chirurgie d'Abulcasis | Traduits à Tolède et Salerne |
| Optique | Traité d'Ibn al-Haytham (Alhazen) | Traduit au XIIIe siècle |
| Chimie | Distillation, pharmacologie | *Al-kīmiyā'* → alchimie → chimie |

**Durée** : ~300 ans de transfert systématique.

## 2. Phase 2 : Expulsion (1492-1609) {#s2}

**Mécanisme** : Une fois le savoir assimilé, l'Europe expulse les communautés qui l'ont transmis.

| Date | Événement | Conséquence |
|------|-----------|-------------|
| 1492 | Expulsion des Juifs d'Espagne (décret de l'Alhambra) | 200 000 personnes, fin de 1 000 ans de présence |
| 1492 | Chute de Grenade | Fin du dernier État musulman d'Ibérie |
| 1497 | Expulsion des Juifs du Portugal | Zacuto lui-même s'exile |
| 1502 | Conversion forcée des Musulmans de Castille | Fin de la pratique islamique légale |
| 1609 | Expulsion des Morisques | ~300 000 personnes vers le Maghreb |

**Point clé** : L'expulsion est *postérieure* à l'assimilation. L'Europe ferme la porte après avoir vidé la maison.

## 3. Phase 3 : Conquête (XVIe-XXe siècles) {#s3}

**Mécanisme** : L'Europe retourne les outils reçus contre ceux qui les ont forgés.

| Conquête | Outils d'origine islamique |
|----------|---------------------------|
| Amériques (1492-1550) | Navigation (astrolabe), poudre, cartographie |
| Inde portugaise (1510) | Tables de Zacuto, artillerie navale |
| Constantinople ottomane résiste puis s'affaiblit | Face à une Europe renforcée par ses propres outils |
| Égypte (1798) | Artillerie (poudre arabo-chinoise), science |
| Algérie (1830) | Artillerie, navires |
| Tunisie (1881), Maroc (1912) | Supériorité technologique globale |
| Moyen-Orient (mandats 1920) | Toute la panoplie |

## 4. Le paradoxe structurel {#s4}

Le schéma réception-expulsion-conquête n'est pas propre à la relation Europe-Islam — c'est une loi de la transmission du savoir :

- Les **Grecs** transmettent leur philosophie aux **Arabes** → les Arabes construisent une civilisation rivale
- Les **Arabes** transmettent cette philosophie aux **Européens** → l'Europe colonise le monde arabe
- L'**Europe** transmet sa technologie aux **colonies** → les colonies se libèrent (XXe siècle)

Le savoir est une arme qui ne reste jamais aux mains de son créateur.
