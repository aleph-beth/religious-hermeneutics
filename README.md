# Midrash — Herméneutique comparée / Comparative Hermeneutics

Essais comparatifs sur les traditions juive, chrétienne et islamique : herméneutique, étymologie sémitique, philosophie et histoire. Chaque article existe en français et en anglais.

Comparative essays on the Jewish, Christian, and Islamic traditions: hermeneutics, Semitic etymology, philosophy and history. Every article exists in French and in English.

**Site : https://aleph-beth.github.io/religious-hermeneutics/**

## Organisation

```
src/content/en/<slug>.md   version anglaise
src/content/fr/<slug>.md   version française
src/data/dossiers.ts       dossiers (séries en plusieurs volets) et catégories
src/pages/                 accueil, /articles/<slug>/, /dossiers/<id>/
scripts/check-content.mjs  vérification des conventions éditoriales
```

Les conventions d'écriture (frontmatter, structure des sections, citations) sont décrites dans [CONTRIBUTING.md](CONTRIBUTING.md). Le tableau des articles ci-dessous est généré par `npm run readme`.

## Développement

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # vérifie les articles
npm run build    # génère dist/
```

Le déploiement sur GitHub Pages se fait automatiquement à chaque fusion dans `main`.
